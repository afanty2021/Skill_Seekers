## 引言
本文系统性地介绍四种文档拆分策略：无拆分、按类别拆分、基于大小拆分以及推荐的路由器+类别模式。每种策略都针对不同规模和结构特征的文档提供了相应的解决方案。通过`split_config.py`工具的`--strategy`参数，用户可以根据实际需求选择最合适的拆分方式。本文将详细说明各种策略的适用场景、技术实现方法和操作流程，并重点剖析路由器+类别模式在智能路由、并行抓取效率提升和用户体验优化方面的优势。

## 无拆分策略

**Section sources**
- [split_config.py](file://src/skill_seekers/cli/split_config.py#L183-L185)

当文档规模较小（少于5000页）时，无需进行拆分。此时`split_strategy`自动设置为"none"，保持单个技能配置文件不变。这种策略适用于内容较少、结构简单的文档，避免了不必要的复杂性。

```bash
# 自动检测无需拆分
python3 split_config.py configs/react.json
```

该命令会输出提示信息："ℹ️ 小型文档（300页） - 无需拆分"，并直接返回原始配置文件。

## 按类别拆分策略

**Section sources**
- [split_config.py](file://src/skill_seekers/cli/split_config.py#L66-L116)
- [LARGE_DOCUMENTATION.md](file://docs/LARGE_DOCUMENTATION.md#L61-L77)

适用于5000-15000页且具有明确主题划分的中型文档。此策略根据配置文件中的`categories`字段将文档拆分为多个专注的子技能。

```bash
# 按类别自动拆分
python3 split_config.py configs/godot.json --strategy category
```

生成的文件命名模式为`{基础名称}-{类别名称}.json`，例如：
- godot-scripting.json
- godot-2d.json
- godot-3d.json

优点是每个子技能聚焦特定主题，缺点是用户需要知道具体使用哪个技能。

## 基于大小拆分策略

**Section sources**
- [split_config.py](file://src/skill_seekers/cli/split_config.py#L125-L147)

适用于缺乏清晰类别的大型文档。此策略根据预设的目标页数（默认5000页）将文档均匀分割。

```bash
# 按大小拆分，每部分3000页
python3 split_config.py configs/bigdocs.json --strategy size --target-pages 3000
```

生成的文件命名模式为`{基础名称}-part{序号}.json`，例如：
- bigdocs-part1.json
- bigdocs-part2.json
- bigdocs-part3.json

优点是简单可预测，缺点是可能将相关主题分割到不同文件中。

## 路由器+类别模式

**Section sources**
- [split_config.py](file://src/skill_seekers/cli/split_config.py#L190-L192)
- [generate_router.py](file://src/skill_seekers/cli/generate_router.py)
- [LARGE_DOCUMENTATION.md](file://docs/LARGE_DOCUMENTATION.md#L81-L97)

这是推荐的拆分策略，特别适合10000页以上的大型文档。该模式创建一个路由器配置和多个基于类别的子技能，实现智能路由和最佳用户体验。

```bash
# 创建路由器+子技能
python3 split_config.py configs/godot-large-example.json --strategy router
```

生成的文件包括：
- godot.json（路由器/中心）
- godot-scripting.json
- godot-2d.json
- 等等

路由器配置包含`_router: True`标记和`_sub_skills`列表，能够根据查询内容智能路由到相应的子技能。这种模式结合了分类拆分的专注性和统一入口的便利性，支持并行抓取，显著提升了处理效率。

## 技术实现与配置解析

**Section sources**
- [split_config.py](file://src/skill_seekers/cli/split_config.py#L39-L64)
- [godot-large-example.json](file://configs/godot-large-example.json#L48-L56)

`split_config.py`首先解析原始配置文件，读取`split_strategy`和`split_config`字段。如果配置中定义了拆分策略，则优先使用；否则根据文档规模自动选择最佳策略：

- 小于5000页：无拆分
- 5000-10000页且有类别：按类别拆分
- 大于10000页且有至少3个类别：路由器+类别模式
- 其他情况：基于大小拆分

`split_config`字段可包含详细配置，如`target_pages_per_skill`、`create_router`、`split_by_categories`等参数，允许精细化控制拆分行为。
