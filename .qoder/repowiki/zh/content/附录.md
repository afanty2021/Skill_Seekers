## API端点汇总

本项目主要通过命令行工具和MCP（Model Context Protocol）工具提供功能，而非传统HTTP API。以下是MCP工具的自然语言调用方式：

| MCP工具 | 自然语言调用示例 | 功能描述 |
|--------|------------------|----------|
| `list_configs` | "列出所有可用配置" | 列出所有预设配置 |
| `fetch_config` | "获取React配置" | 从API或Git源获取配置 |
| `scrape_docs` | "使用react.json抓取文档" | 执行文档抓取 |
| `package_skill` | "打包React技能" | 将输出打包为.zip文件 |
| `upload_skill` | "上传React技能到Claude" | 自动上传技能到Claude |
| `enhance_skill` | "增强React技能" | 使用AI增强SKILL.md |
| `add_config_source` | "添加名为'team'的配置源" | 注册新的Git配置源 |
| `list_config_sources` | "列出所有配置源" | 显示已注册的配置源 |
| `remove_config_source` | "移除名为'team'的配置源" | 注销配置源 |

## 技术术语与缩写解释

| 术语/缩写 | 解释 |
|---------|------|
| **MCP (Model Context Protocol)** | 模型上下文协议，一种允许AI模型与外部工具交互的标准。 |
| **CLI (Command Line Interface)** | 命令行界面，用户通过文本命令与程序交互的方式。 |
| **API (Application Programming Interface)** | 应用程序编程接口，允许不同软件组件相互通信的定义和协议。 |
| **AST (Abstract Syntax Tree)** | 抽象语法树，源代码语法结构的树状表示。 |
| **SSR (Server-Side Rendering)** | 服务端渲染，在服务器上生成HTML并发送到客户端。 |
| **SSG (Static Site Generation)** | 静态站点生成，在构建时生成静态HTML文件。 |
| **ORM (Object-Relational Mapping)** | 对象关系映射，将数据库表映射到编程语言对象的技术。 |
| **CLI工具** | 命令行工具，通过命令行执行特定任务的程序。 |
| **MCP工具** | 通过MCP协议集成到AI中的工具，可通过自然语言调用。 |
| **统一抓取 (Unified Scraping)** | 结合文档、代码库、PDF等多种来源创建统一技能的过程。 |
| **技能 (Skill)** | Claude AI中的功能模块，包含特定领域的知识和能力。 |
| **增强 (Enhancement)** | 使用AI改进SKILL.md内容，提高其质量和实用性。 |

## 项目演进分析摘要

### A1.9多源架构演进
项目正从单一源系统向多源联邦系统演进：
- **当前状态**：单一公共仓库（skill-seekers-configs）
- **未来状态**：支持多个Git仓库作为配置源，包括公共和私有仓库
- **优势**：支持团队协作、个人配置、自定义集合和去中心化系统

### 三大发展愿景
1. **第一阶段：官方配置** - 已完成，提供集中式、经过验证的配置。
2. **第二阶段：多源联邦** - 支持多个Git仓库作为配置源，实现去中心化、用户控制的配置管理。
3. **第三阶段：技能市场** - 构建完整的生态系统，支持共享配置和技能，具有评级、流行度和持续更新功能。

### 关键技术决策
- **Git仓库 vs API vs 数据库**：选择Git仓库，因其符合开发者工作流、去中心化且免费托管。
- **缓存策略**：采用浅克隆（shallow clone）与基于TTL的自动刷新，平衡速度与新鲜度。
- **令牌存储**：优先使用keyring进行安全存储，环境变量作为回退方案。

### 设计优势
- **网络效应**：更多来源 → 更多配置 → 更高价值
- **零锁定**：支持任何Git托管服务（GitHub、GitLab、Bitbucket等）
- **隐私优先**：敏感配置可保持私有
- **团队友好**：适合3-5人团队使用
- **去中心化**：无单点故障

## 故障排除指南

### 安装问题
- **Python未找到**：检查Python是否安装，使用`brew install python3`（macOS）或`sudo apt install python3`（Linux）安装。
- **模块未找到**：使用`pip3 install requests beautifulsoup4`安装依赖。
- **权限被拒绝**：使用`--user`标志或创建虚拟环境。

### 运行时问题
- **文件未找到**：确保在正确的目录中运行命令。
- **配置文件未找到**：检查`configs/`目录是否存在所需配置文件。

### MCP设置问题
- **MCP服务器未加载**：检查`~/.config/claude-code/mcp.json`中的路径是否为绝对路径，重新运行`./setup_mcp.sh`，并完全重启Claude Code。
- **工具出现但无法工作**：验证工作目录和文件路径是否正确。

### 抓取问题
- **缓慢或挂起**：检查网络连接，减少`max_pages`进行测试，或增加`rate_limit`。
- **无内容提取**：检查配置中的选择器是否正确，验证网站是否可访问。
- **速率限制/429错误**：增加`rate_limit`，减少`max_pages`，或稍后重试。

### 平台特定问题
- **macOS**：使用`chmod +x setup_mcp.sh`使脚本可执行。
- **Linux**：使用`sudo apt install python3-pip`安装pip3。
- **Windows (WSL)**：确保Python在PATH中，使用`dos2unix`转换行尾。
